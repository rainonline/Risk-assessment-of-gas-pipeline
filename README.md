# 燃气管道风险评价程序 - Vue 3 版本

现代化的燃气管道风险评价工具，使用 Vue 3 + Element Plus 构建。

## 🚀 技术栈

- **Vue 3** - 现代化的 JavaScript 框架
- **Vite** - 快速的构建工具和开发服务器
- **Element Plus** - Vue 3 UI 组件库
- **Vue Router 4** - 客户端路由
- **Pinia** - 状态管理
- **JavaScript ES6+** - 现代化 JavaScript 特性

## ✨ 功能特性

### 核心功能
- 🏗️ **多维度风险评价**：第三方破坏、腐蚀、设计因素、误操作、泄露分/人口分
- 📊 **智能结果分析**：自动生成风险评价报告和统计数据
- 🎯 **模拟模式**：快速体验完整评价流程
- 📈 **实时进度跟踪**：可视化评价完成状态

### 用户体验
- 📱 **响应式设计**：完美适配桌面和移动设备
- 🎨 **现代化界面**：Material Design 风格的用户界面
- ⚡ **快速加载**：优化的代码分割和懒加载
- 🔄 **流畅交互**：平滑的页面过渡和动画效果

### 开发体验
- 🛠️ **热重载开发**：代码更改实时生效
- 📦 **组件化架构**：可维护的代码结构
- 🔧 **TypeScript 准备**：框架支持 TypeScript 扩展
- 📋 **代码规范**：ESLint 和 Prettier 集成

## 🎯 使用指南

### 1. 开始评价
1. 在欢迎页面输入管道名称
2. 点击"进入评价系统"

### 2. 完成评价
1. 在主控制面板选择评价项目
2. 完成各项风险因素选择
3. 保存并返回主页面

### 3. 生成结果
1. 完成所有评价项目后
2. 点击"计算生成"查看结果

### 4. 模拟模式
- 点击"模拟模式"可快速体验完整流程
- 模拟结果仅供参考，不代表真实评价
